# l4kr assets

Public assets used by l4kr projects.

## Futonarr

The Futonarr play emblem uses a cyan, violet, and pink gradient on a transparent background.

- `futonarr/logo.png`: full-resolution source artwork.
- `futonarr/64.png`, `futonarr/128.png`, `futonarr/256.png`: notification icons.
- `futonarr/96-Outline-White.png`: white Android notification icon with transparent padding.

Files are served from `https://raw.githubusercontent.com/l4kr/l4kr-assets/main/futonarr/`.
